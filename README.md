## 🧪 API Automation Project — Stellar Burgers

Автоматизированные тесты для API сервиса заказа бургеров [Stellar Burgers](https://stellarburgers.nomoreparties.site).  
Проект реализован с использованием **Python** и **pytest**, охватывает ключевые функции API: авторизация, заказы, изменение данных пользователя и другое.

---

### 🔧 Установка зависимостей

```bash
pip install -r requirements.txt
```
### 🚀 Запуск тестов

```bash
pytest tests -v
